## 判讀規則（只記看得到的，看不到就填 null／unknown，不猜）

1. 每張照片分開判讀，各記一組：
   - `lanes`：拍攝者這個行進方向、汽車可行駛的一般車道數（整數）。看不清、被前車擋住、車道線磨損無法確定 → `null`。
   - `vis`：`clear`＝這個方向每一條車道的邊線都看得清楚、數得出來；`partial`＝只看得到部分；`none`＝看不到。
   - `moto`：這個方向最外側有沒有以實線或標字分開的機慢車道／機車專用道：`yes`、`no`、`unknown`。
   - `median`：與對向之間有沒有實體分隔島（緣石、植栽、護欄、紐澤西護欄）：`yes`；只有標線（雙黃線、黃斑馬）或沒有：`no`；看不到：`unknown`。單行道或國道看不到對向時依中央是否有實體分隔判斷。
   - `tl`：一律填空字串 `""`（路段不判轉向箭頭）。
2. 車道計數（台灣情境）：
   - 只算汽車可行駛的一般車道；「機慢車優先」但汽車仍可行駛的混合車道算一般車道。
   - 機慢車道（實線隔開、標「機慢車」）、路肩、停車格、公車專用道不算，在 `moto` 或 note 註記。
   - 對向車道不算。快慢分隔的道路，只算照片所在那一側的車道（例如在慢車道就只數慢車道），並在 note 寫「快慢分隔，在快／慢車道側」。
   - 匯入、加減速車道、正在增減車道的位置，在 note 註記，`lanes` 照實數但 `vis` 不可填 clear。
3. 高架誤配：照片若明顯拍在與標示道路等級不符的高架／平面道路上（例如標示 primary 卻在高架快速道路上，或標示 motorway 卻在平面道路），在 note 寫「照片在高架道路上」或「照片不在該道路」，該張 `lanes` 填 null、`vis` 填 none。
4. 夜間、模糊、被大車擋住，照實填 null／none／unknown，不要補。

## 輸出

最後的回覆只能是一個 JSON 物件（第一個字元是 `{`、最後一個字元是 `}`；不要 markdown 圍欄、不要「完成 N 筆」之類的說明文字、不要寫檔）。每個標籤一筆，`a`／`b` 各五個欄位 `lanes`、`tl`、`vis`、`moto`、`median` 缺一不可，`note` 可省略，不要加其他欄位：

{"B123": {"a": {"lanes": 2, "tl": "", "vis": "clear", "moto": "yes", "median": "no"}, "b": {"lanes": null, "tl": "", "vis": "none", "moto": "unknown", "median": "unknown"}, "note": "可選，簡短備註"}}

欄位值只能用：`vis` ∈ clear／partial／none；`moto`、`median` ∈ yes／no／unknown；`lanes` 是 1–12 的整數或 null；`tl` 一律 ""。這一批列出的每個標籤都必須出現在輸出中。
