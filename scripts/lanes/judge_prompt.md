## 判讀規則（只記看得到的，看不到就留空，不猜）

1. 每張照片分開判讀，各記一組：
   - `lanes`：該行進方向、汽車可行駛的一般車道數（整數）。看不清、被前車擋住、無法確定 → `null`。
   - `tl`：OSM `turn:lanes` 格式，由左到右、以 `|` 分隔，段數必須等於 `lanes`。箭頭值用 `left`、`through`、`right`、`reverse`，同一車道多個箭頭用分號，例如 `left|through|through;right`。**只記地面上真的看得到的箭頭**；有任何車道箭頭看不到、或 `lanes` 是 null，就整個留空字串 `""`。不要依路型、常識或另一張照片推測。
   - `vis`：`clear`＝所有車道的箭頭都看得到；`partial`＝只看得到部分車道的箭頭；`none`＝完全看不到箭頭。
2. 車道計數（台灣情境）：
   - 只算汽車可行駛的一般車道；「機慢車優先」但汽車仍可行駛的混合車道算一般車道。
   - 以實線邊線隔開的路肩、停車格、外側慢車道不算；純機車專用道不算（在 note 註記）。
   - 機車停等區、待轉區是路口標線，不算車道，可在 note 註記。
   - 對向車道不算。
3. 透視：右側車道往左上斜的箭頭通常是透視造成的直行，記 `through`。
4. 高架誤配：照片若明顯拍在高架道路／快速道路上（看得到護欄高架、下方是另一層道路、或與標示的道路等級明顯不符），在該方向的 `note` 寫「照片在高架道路上」，該張 `lanes` 填 null、`tl` 留空、`vis` 填 none。
5. 照片看不到路口（例如被大車擋住、夜間、模糊），照實填 null／""／none，不要補。

## 輸出

用 Write 工具把結果寫成 UTF-8 JSON 到：{{OUT}}
格式（每個標籤一筆，`note` 可省略；不要加其他欄位，不要包 markdown）：

```
{
  "A123": {"a": {"lanes": 3, "tl": "left|through|through;right", "vis": "clear"},
           "b": {"lanes": null, "tl": "", "vis": "none"},
           "note": "可選，簡短備註"}
}
```

這一批列出的每個標籤都必須出現在輸出中。寫完檔案就結束，最後只回一行「完成 N 筆」。
